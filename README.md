# Driver Reinstaller ⚡

Простая, функциональная и красивая утилита на Python для автоматической диагностики, обслуживания и переустановки/обновления драйверов видеокарт (дискретных GPU и встроенных iGPU) на Windows.

## 🚀 Возможности

- **Автообнаружение видеоадаптеров**: определяет все GPU/iGPU через Windows WMI (NVIDIA, AMD Radeon, Intel HD/UHD/Iris).
- **Продвинутый дашборд**:
  - Отображение текущего разрешения экрана и частоты обновления (например, `1920x1080 @ 180 Гц`).
  - Объем видеопамяти (VRAM), дата выпуска и точная версия драйвера.
  - Удобное копирование PNP Hardware ID в 1 клик.
- **Глубокая переустановка**:
  - При наличии `devcon.exe`: выполняет полное аппаратное удаление устройства из диспетчера и перескан шины (`devcon remove` -> `devcon rescan`).
  - Без devcon: выполняет безопасную переинициализацию через `pnputil` и командлеты PowerShell (`Disable-PnpDevice` / `Enable-PnpDevice`).
- **Автозагрузка devcon.exe**: скачивает и распаковывает официальный подписанный `devcon.exe` из Microsoft WDK CAB-пакетов в один клик.
- **🛡️ Точка восстановления Windows**: создает мгновенную контрольную точку восстановления системы перед началом любых манипуляций с драйверами.
- **💾 Резервное копирование драйверов**: экспортирует все установленные OEM-драйверы в указанную папку через `pnputil /export-driver`.
- **⚡ Сброс видеоподсистемы (Win + Ctrl + Shift + B)**: программный перезапуск видеодрайвера в один клик при зависаниях или черном экране.
- **🧹 Очистка шейдерного кэша**: очищает кэш шейдеров DirectX, Vulkan, NVIDIA, AMD и Intel, устраняя микрофризы и статтеры в играх после смены драйвера.
- **Быстрый переход к свежим драйверам**: открывает официальные страницы загрузки NVIDIA, AMD или Intel.
- **Портативный автозапуск**: батник `setup_and_run.bat` автоматически скачает и настроит Python и необходимые библиотеки на любом чистом ПК без установки вручную.

## 📦 Быстрый старт

### Вариант 1: Запуск на любом ПК (даже без установленного Python)
Просто скачайте проект (или скопируйте на флешку) и запустите:
```cmd
setup_and_run.bat
```
Скрипт автоматически:
1. Проверит наличие Python 3.10+.
2. Если Python нет — скачает и установит официальный Python.
3. Установит нужные зависимости (`wmi`, `requests`, `pywin32`).
4. Запустит приложение без лишних консольных окон.

### Вариант 2: Запуск вручную
Если Python уже установлен:
```bash
pip install -r requirements.txt
python driver_reinstaller.py
```
> **Важно**: для операций управления драйверами требуются права администратора (приложение запросит перезапуск от имени администратора автоматически).
